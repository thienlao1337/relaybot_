# Relay Assistant Bot

Telegram-бот на aiogram 3: менеджер задач, погода и курсы валют через открытые API,
AI-помощник поверх LLM, встроенный мини-веб-интерфейс (Telegram Mini App), приём оплаты
через Telegram Stars, inline-режим (`@bot запрос` в любом чате) и рассылка для администратора.

## Возможности

- 📝 Задачи с сохранением между сессиями (SQLite)
- 🌦 Погода по названию города (open-meteo.com, без API-ключа)
- 💱 Курсы валют к гривне (open.er-api.com, без API-ключа)
- 🤖 AI-помощник поверх Gemini (бесплатно), Anthropic Claude или OpenAI (опционально, по своему API-ключу)
- 🖥 Mini App — три вкладки (задачи, погода, курсы) в полноценном веб-интерфейсе внутри Telegram,
  с проверкой подлинности запросов по официальному алгоритму валидации `initData`
- ⭐ Приём оплаты через Telegram Stars — нативная валюта Telegram, без стороннего провайдера
- 🔎 Inline-режим: `@ваш_бот Kyiv` или `@ваш_бот usd` работает в любом чате, не только в переписке с ботом
- 🌐 Переключение языка интерфейса на лету (украинский / английский / русский)
- 🔐 Команда `/broadcast` только для администратора
- ⚙️ Один и тот же код запускается и в режиме long polling (локально), и в режиме webhook (продакшен)

## Стек

Python 3.12 · [aiogram 3](https://docs.aiogram.dev/) · aiohttp · aiosqlite · Docker

## Установка и запуск (локально)

1. Получите токен бота у [@BotFather](https://t.me/BotFather): `/newbot` → следуйте инструкциям.
2. Скопируйте `.env.example` в `.env` и впишите токен:
   ```
   cp .env.example .env
   ```
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   python main.py
   ```
4. Напишите боту `/start` в Telegram.

Локально (`RUN_MODE=polling`) недоступны только те функции, которым нужен публичный HTTPS-адрес —
Mini App и webhook. Задачи, погода, курсы, AI-помощник, Stars-оплата и inline-режим работают и так.

## Дополнительные переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_ID` | нет | ваш числовой Telegram id (для `/broadcast`), берётся у @userinfobot |
| `GEMINI_API_KEY` | нет | включает AI-помощника через Google Gemini — **бесплатный тариф, без карты**, проверяется первым |
| `ANTHROPIC_API_KEY` | нет | включает AI-помощника через Claude (платно, используется если Gemini-ключ не задан) |
| `OPENAI_API_KEY` | нет | включает AI-помощника через OpenAI (платно, используется если ни один из двух выше не задан) |
| `STARS_PRICE` | нет | цена демо-платежа в Telegram Stars, по умолчанию `1` |
| `WEBHOOK_HOST` | только для webhook | публичный HTTPS-адрес сервиса, из него же строится адрес Mini App |

Если ни один из трёх ключей не задан — кнопка AI-помощника остаётся в меню, но по нажатию честно
сообщает, что функция не настроена, вместо ошибки.

Бесплатный вариант — **Gemini**: console.google.dev / aistudio.google.com → Get API key,
без привязки карты, ~1500 запросов в день на модели Flash/Flash-Lite. Google оговаривает, что
данные бесплатного тарифа могут использоваться для улучшения моделей — если это критично,
берите платный тариф или Anthropic/OpenAI.

## Деплой

Проект готов к деплою на [Render](https://render.com) как Docker Web Service — конфигурация
уже описана в `render.yaml` и `Dockerfile`.

1. Залейте репозиторий и подключите его в Render (New → Web Service).
2. Добавьте переменные окружения из таблицы выше, какие нужны.
3. После первого деплоя скопируйте выданный Render URL и добавьте его в переменную
   `WEBHOOK_HOST` (без слэша в конце) — сервис передеплоится, зарегистрирует webhook и заодно
   мини-приложение станет доступным по кнопке "Відкрити застосунок".
4. В @BotFather включите инлайн-режим: `/setinline` → выберите бота → впишите любую подсказку
   (например "Напишите город или usd").

На бесплатном тарифе Render сервис засыпает после ~15 минут без запросов и просыпается по
первому входящему сообщению за 30-60 секунд — Telegram в этот момент просто повторяет доставку.
Для инстанса без засыпания подойдёт платный план Render или любой VPS.

## Структура проекта

```
config.py           — конфигурация из переменных окружения
db.py                — слой хранения (SQLite): пользователи, задачи
i18n.py               — тексты интерфейса на трёх языках
handlers.py           — хендлеры, клавиатуры, бизнес-логика (задачи, погода, валюта, AI, Stars)
inline_handlers.py    — обработчик inline-режима
llm.py                — обёртка над Anthropic / OpenAI chat API
security.py           — валидация Telegram WebApp initData
webapp_page.py         — HTML/JS мини-приложения (Telegram Mini App)
api.py                 — REST-эндпоинты для мини-приложения
main.py                — точка входа: polling или webhook (переключается RUN_MODE)
Dockerfile              — образ для деплоя
render.yaml             — конфигурация сервиса Render
```
