# Relay Assistant Bot

Telegram-бот на aiogram 3: менеджер задач, погода и курсы валют через открытые API,
AI-помощник поверх LLM с ответами на основе базы знаний (RAG), фоновые алерты по курсу валют,
встроенный мини-веб-интерфейс (Telegram Mini App) с админ-панелью, приём оплаты через
Telegram Stars, inline-режим (`@bot запрос` в любом чате).

## Возможности

- 📝 Задачи с сохранением между сессиями
- 🌦 Погода по названию города (open-meteo.com, без API-ключа)
- 💱 Курсы валют к гривне (open.er-api.com, без API-ключа)
- 🔔 Алерты по курсу — «сообщи, когда USD выше/ниже X»: фоновая задача опрашивает курсы и
  присылает уведомление, как только порог пройден (см. `watch_service.py`)
- 🤖 AI-помощник поверх Gemini (бесплатно), Anthropic Claude или OpenAI (опционально, по своему
  API-ключу), с retrieval-augmented ответами: вопросы о самом боте отвечаются строго по
  встроенной базе знаний (`knowledge_base.py`), а не выдумываются — если ответа там нет,
  бот честно об этом говорит
- 🖥 Mini App — четыре вкладки (задачи, погода, курсы, admin) в полноценном веб-интерфейсе
  внутри Telegram, с проверкой подлинности запросов по официальному алгоритму валидации `initData`
- 🛠 Админ-панель в Mini App (видна только `ADMIN_ID`): статистика по пользователям/задачам/
  алертам и рассылка всем пользователям прямо из интерфейса
- ⭐ Приём оплаты через Telegram Stars — нативная валюта Telegram, без стороннего провайдера
- 🔎 Inline-режим: `@ваш_бот Kyiv` или `@ваш_бот usd` работает в любом чате, не только в переписке с ботом
- 🌐 Переключение языка интерфейса на лету (украинский / английский / русский)
- 🔐 Команда `/broadcast` и админ-эндпоинты API — только для администратора
- 🗄 SQLite из коробки, переключение на PostgreSQL одной переменной окружения (см. ниже)
- ⚙️ Один и тот же код запускается и в режиме long polling (локально), и в режиме webhook (продакшен)

## Стек

Python 3.12 · [aiogram 3](https://docs.aiogram.dev/) · aiohttp · SQLAlchemy 2 (async) ·
SQLite / PostgreSQL · Docker

## Установка и запуск (локально)

1. Получите токен бота у [@BotFather](https://t.me/BotFather): `/newbot` → следуйте инструкциям.
2. Скопируйте `.env.example` в `.env` и впишите токен:
   ```
   cp .env.example .env
   ```
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   python main.py
   ```
4. Напишите боту `/start` в Telegram.

Локально (`RUN_MODE=polling`) недоступны только те функции, которым нужен публичный HTTPS-адрес —
Mini App и webhook. Задачи, погода, курсы, AI-помощник, Stars-оплата и inline-режим работают и так.

## Дополнительные переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_ID` | нет | ваш числовой Telegram id (для `/broadcast`), берётся у @userinfobot |
| `GEMINI_API_KEY` | нет | включает AI-помощника через Google Gemini — **бесплатный тариф, без карты**, проверяется первым |
| `ANTHROPIC_API_KEY` | нет | включает AI-помощника через Claude (платно, используется если Gemini-ключ не задан) |
| `OPENAI_API_KEY` | нет | включает AI-помощника через OpenAI (платно, используется если ни один из двух выше не задан) |
| `STARS_PRICE` | нет | цена демо-платежа в Telegram Stars, по умолчанию `1` |
| `WEBHOOK_HOST` | только для webhook | публичный HTTPS-адрес сервиса, из него же строится адрес Mini App |
| `DATABASE_URL` | нет | строка подключения к PostgreSQL; не задано — используется SQLite по `DB_PATH` |
| `PRICE_WATCH_ENABLED` | нет | `true`/`false`, фоновый опрос курсов для алертов, по умолчанию включён |

Если ни один из трёх ключей не задан — кнопка AI-помощника остаётся в меню, но по нажатию честно
сообщает, что функция не настроена, вместо ошибки.

Бесплатный вариант — **Gemini**: console.google.dev / aistudio.google.com → Get API key,
без привязки карты, ~1500 запросов в день на модели Flash/Flash-Lite. Google оговаривает, что
данные бесплатного тарифа могут использоваться для улучшения моделей — если это критично,
берите платный тариф или Anthropic/OpenAI.

### Если AI-помощник отвечает ошибкой вида "model ... is no longer available"

Провайдеры периодически снимают с поддержки старые версии моделей и заменяют их новыми —
и Gemini, и Anthropic, и OpenAI. Если бот вернул ошибку в духе `model X is no longer available,
use model Y instead`, самое быстрое решение — не трогать код, а задать модель через переменную
окружения на Render (Environment → Add Environment Variable) и передеплоить:

| Провайдер | Переменная | Дефолт в коде на момент написания |
|---|---|---|
| Gemini | `GEMINI_MODEL` | `gemini-3.5-flash-lite` |
| Anthropic | `ANTHROPIC_MODEL` | `claude-haiku-4-5-20251001` |
| OpenAI | `OPENAI_MODEL` | `gpt-5.6-luna` |

Значение берите прямо из текста ошибки (провайдеры обычно сами подсказывают актуальный id) или
из официальной документации провайдера. Дефолты в `config.py` тоже стоит обновить, если ошибка
повторяется у всех, кто разворачивает проект заново.

## PostgreSQL вместо SQLite

По умолчанию бот пишет в SQLite-файл — ничего настраивать не нужно, подходит для локальной
разработки и демо. Для продакшена достаточно одной переменной:

1. Создайте базу (например, бесплатный Render Postgres, или любой другой провайдер).
2. Скопируйте выданную строку подключения (`postgres://...` или `postgresql://...`) в
   `DATABASE_URL` — схема нормализуется автоматически под asyncpg-драйвер, вставлять как есть.
3. Передеплойте. `db.py` использует SQLAlchemy 2 (async ORM) — модели и запросы не меняются
   между SQLite и Postgres, при старте таблицы создаются автоматически (`init_db()`).

Существующие данные в SQLite при переключении не переносятся автоматически — для реального
продакшена с историей данных нужна отдельная миграция (например, через `pgloader` или
экспорт/импорт), это осознанно не входит в объём демо-проекта.

## Алерты по курсу и фоновые задачи

`watch_service.py` — отдельный `asyncio`-цикл, который раз в 5 минут опрашивает курсы валют и
уведомляет пользователей, чьи пороги (`/watch` или кнопка «🔔 Курс-алерт») сработали, после чего
деактивирует сработавший алерт. Цикл стартует как фоновая задача на том же event loop, что и сам
бот — отдельный воркер или очередь задач не нужны, см. `main.py`.

На бесплатном тарифе Render это означает, что сервис не будет засыпать сам по себе (что вообще-то
обычно плюс для бота, но расходует часы бесплатного тарифа быстрее) — отключается переменной
`PRICE_WATCH_ENABLED=false`.

## Деплой

Проект готов к деплою на [Render](https://render.com) как Docker Web Service — конфигурация
уже описана в `render.yaml` и `Dockerfile`.

1. Залейте репозиторий и подключите его в Render (New → Web Service).
2. Добавьте переменные окружения из таблицы выше, какие нужны.
3. После первого деплоя скопируйте выданный Render URL и добавьте его в переменную
   `WEBHOOK_HOST` (без слэша в конце) — сервис передеплоится, зарегистрирует webhook и заодно
   мини-приложение станет доступным по кнопке "Відкрити застосунок".
4. В @BotFather включите инлайн-режим: `/setinline` → выберите бота → впишите любую подсказку
   (например "Напишите город или usd").

На бесплатном тарифе Render сервис засыпает после ~15 минут без запросов и просыпается по
первому входящему сообщению за 30-60 секунд — Telegram в этот момент просто повторяет доставку.
Для инстанса без засыпания подойдёт платный план Render или любой VPS.

## Структура проекта

```
config.py           — конфигурация из переменных окружения
db.py                — слой хранения (SQLAlchemy async): пользователи, задачи, алерты, статистика
knowledge_base.py    — мини-база знаний и поиск по ней для RAG-ответов AI-помощника
watch_service.py     — фоновый цикл опроса курсов и уведомлений по алертам
i18n.py              — тексты интерфейса на трёх языках
handlers.py          — хендлеры, клавиатуры, бизнес-логика (задачи, погода, валюта, алерты, AI, Stars)
inline_handlers.py   — обработчик inline-режима
llm.py               — обёртка над Gemini / Anthropic / OpenAI chat API, поддержка RAG-контекста
security.py          — валидация Telegram WebApp initData
webapp_page.py       — HTML/JS мини-приложения (Telegram Mini App), включая admin-вкладку
api.py               — REST-эндпоинты для мини-приложения, в т.ч. /api/admin/*
main.py              — точка входа: polling или webhook (переключается RUN_MODE)
Dockerfile           — образ для деплоя
render.yaml          — конфигурация сервиса Render
```
